## Canonical V2 design system reference

For EVERY screen retrofit in this inventory, the following canonical rules apply (founder locks ma23-may30) :

- **Bottom nav** = 5 slots (Home / Play / +create / Msg / Profile-SQUARE-mint-frame) — `bnav-canonical` class
- **Tab pills (active)** = card bg + mint text + mint border 1.5px + halo box-shadow (NOT gradient mint)
- **Icon tiers** :
  - T1 chip (decorative row icon) : 32×32, hue bg + halo glow
  - T2 action btn (clickable standalone) : 36×36, mint border + double glow
  - T3 inline icon (in pill/CTA text) : 14×14, no bg, same color as text
  - T4 bottom nav icon : 24×24, no bg
- **Cards** = mint identity glow (1.5px border + box-shadow 24px mint .10)
- **Primary CTA** = gradient mint pill (full-width 54h)
- **Body** = 393×852 device format native (no scaffold)
- **Palette** : mint `#26C1A4`, mint-hi `#11E3A3`, mint-deep `#00B3C7`, dark `#000000`, card-dark `#14141A`, card-light `#FFFFFF`
- **Font** : Plus Jakarta Sans (400/500/600/700/800)
