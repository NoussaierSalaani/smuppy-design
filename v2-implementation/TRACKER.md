## Conventions (decided during Phase 1 — apply to ALL future Views)
- **i18n**: strings-via-props (Views pure, NO `useTranslation`); per-view namespace file `src/i18n/locales/{fr,en,es,pt-BR}/v2<ViewName>.json` — **camelCase, NO underscore** (e.g. `v2ProfileHeader.json`, NOT `v2_profileheader.json`). The taxonomy test (`src/__tests__/i18n/taxonomy.test.ts`) requires `namespace.feature` camelCase; underscore namespaces FAIL it. Key sets byte-identical ×4.
- **GATE must include the i18n suite**: every batch's authoritative gate runs `npx jest src/__tests__/i18n` (taxonomy + locale symmetry), NOT only the v2 component suites. (Batches 1-2 shipped a red taxonomy test because the i18n suite wasn't gated — fixed + renamed in `8948620be`.)
- **Back-button a11y prop** = `backA11yLabel` (NOT `backLabel`). Primary-CTA a11y = `<action>A11yLabel`. Default back glyph fallback = `'‹'` (never `null` → ghost button).
- **Async money/auth CTAs** expose `<action>Loading?: boolean` → `loading` on the Button atom (derives busy+disabled) = double-submit guard (directive #18 at presentational layer).
- **WCAG contrast class trap**: NEVER pair a theme-CONSTANT colored surface (primarySoft/primaryAccent/*Soft) with a theme-ADAPTIVE text token (`primary`, `onSurface`) — fails AA in one mode. Use a constant ink (`primaryDeep`) or the canonical adaptive PAIR (`primary`/`onPrimary`). Add a `getContrastRatio` light+dark test.
- **Root style**: `flex:1` in `StyleSheet.create`; only `backgroundColor` dynamic via array-merge.
- **Decorative glyphs**: `importantForAccessibility="no"` + `accessibilityElementsHidden`.
